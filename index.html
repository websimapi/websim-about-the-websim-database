The Websim Database

A guide to the built-in, real-time database for creating collaborative applications.

Core Concept

The database is accessed via a global WebsimSocket object. It's a persistent, real-time data store designed for multi-user applications. All data is scoped to the specific instance of the application.

// Setup is simple and done at the global scope
const room = new WebsimSocket();

Data Structure: Records

Records are JSON-like objects. When you create one, some fields are automatically added and managed for you:

  • id: A unique identifier for the record.
  • type: A string you define to categorize the record (e.g., 'post', 'comment').
  • username: The username of the user who created the record.
  • created_at: A UTC timestamp of when the record was created.

You can add any other custom fields you need to a record.

Basic Operations (CRUD)

Creating Records

Use the create method on a collection. A collection is a group of records of the same type.

// Create a "post" record
const post = await room.collection('post').create({
  message: "Hello, real-time world!",
  likes: 0,
});

Getting Records

Use getList to retrieve records. You can also filter them based on their fields.

// Get all records of type "post"
const posts = room.collection('post').getList();

// Get all comments for a specific post
const comments = room.collection('comment')
    .filter({ post_id: post.id })
    .getList();

Updating & Deleting Records

You can only modify or delete records that you have created.

// Update a record
await room.collection('post').update(post.id, {
  message: "This is an updated message.",
});

// Delete a record
await room.collection('post').delete(post.id);

Real-time Subscriptions

The most powerful feature is subscribing to data changes. Your code runs immediately with the current data, and then again every time the data is updated.

// Subscribe to all changes for "post" records
const unsubscribe = room.collection('post').subscribe((posts) => {
  // This function runs whenever the list of posts changes.
  // You would typically re-render your UI here.
  console.log("Updated posts:", posts);
});

React 18 Integration

The database works seamlessly with React's useSyncExternalStore hook, making it easy to build reactive UIs that always show the latest data.

import { useSyncExternalStore } from 'react';

function PostList() {
  // The 'posts' constant will always be up-to-date!
  const posts = useSyncExternalStore(
    room.collection('post').subscribe,
    room.collection('post').getList
  );

  return (
    <ul>
      {posts.map(post => <li key={post.id}>{post.message}</li>)}
    </ul>
  );
}
